ChannelGate brings coding agents into Slack, Microsoft Teams, and Google Chat. Your deployment runs on your Linux infrastructure, with a separate workspace, container, and persistent memory for each conversation. Each thread keeps its own agent session.

Start with a walkthrough, explore a feature, or find the setting you need. Microsoft Teams and Google Chat are currently in Beta.
