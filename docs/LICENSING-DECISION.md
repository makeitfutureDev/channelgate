# Licensing rationale and history

ChannelGate uses source-available terms to permit internal deployments and dedicated customer
service work while reserving paid product distribution, shared customer hosting and rebranding
for separate commercial agreements. This is a product licensing choice, not an OSI open-source license.

The operative terms are [LICENSE.md](../LICENSE.md) and [the EE exception](../src/ee/LICENSE-EE.md).
The [FAQ](LICENSING-FAQ.md) explains common cases. Core security protections are available in every
tier; optional Enterprise integrations are identified explicitly.

Version 1.2 accompanied the initial public release. Version 1.3 clarifies unchanged bundled EE
redistribution and no-key use, contribution permissions, and the Enterprise SDK boundary.
Earlier drafting discussions and private operational plans are not part of the public grant.
See the root license's version history for dates. No published version has automatic relicensing.
